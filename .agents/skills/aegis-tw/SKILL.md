# Aegis Teamwork Alias (/aegis-tw)

Alias pointing to `/tw` and `aegis tw`. See [tw](../tw/SKILL.md) for full reference.

## Quick Invocations
- `/aegis-tw`: Inspect subagent tracks and mutex locks (`aegis tw:status`).
- `/aegis-tw "<objective>"`: Direct subagent plan and staging (`aegis tw "<objective>"`).
- `/aegis-tw:waves [objective]`: Compute execution waves and concurrent batches (`aegis tw:waves`).
- `/aegis-tw:peers`: List active peer subagents in current wave (`aegis tw:peers`).
- `/aegis-tw:radar`: Inspect Conflict Radar for file collision warnings (`aegis tw:radar`).
- `/aegis-tw:doc`: Synthesize living architecture report (`aegis tw:doc`).
- `/aegis-tw clear`: Clear task inbox and release file mutex locks (`aegis tw:clear`).
